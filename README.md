## Título del proyecto
web-corazones-gentiles

## Descripción del proyecto
Corazones Gentiles es una página web solidaria destinada a una jornada para adultos mayores. Contará con información sobre la actividad, un carrusel de imágenes, requisitos de participación, formulario de voluntarios, control de asistencia y sistema de donaciones.

También incluirá estadísticas, ubicación y contacto. La página será desarrollada con HTML, CSS y JavaScript, utilizando localStorage para almacenar los datos.

## Objetivo del proyecto
El objetivo es brindar una herramienta digital que facilite la organización de la jornada solidaria para adultos mayores. Se busca mejorar la comunicación entre la organización, los voluntarios y los participantes, haciendo más sencilla la gestión de las actividades, la colaboración y el control.
